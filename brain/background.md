# Project background

MDWriter is a full-featured, elegant native macOS Markdown document editor built on top of MDEditorKit. It provides an intuitive writing workspace with integrated AI assistance, document outline, and multi-format export.

## Goals
- Deliver a distraction-free writing environment for macOS.
- Deep integration with MDEditorKit for inline Markdown styling.
- Native AI chat and text-assistance features.
